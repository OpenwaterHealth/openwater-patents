This repository contains Openwater's complete patent portfolio and the Openwater Patent Pledge, which grants open access to use these patents for open-source medical device development.

---

## 🌊 About This Repository

Openwater has committed to being the world's first **open-source, open-patent** medical device company. This repository provides:

- **Complete patent listing** with status, filing dates, and descriptions
- **Openwater Patent Pledge** (PDF) — the legal document granting usage rights
- **Links to patent documents** on the official Openwater patents page

> **Patent Usage**: All patents in this repository are governed by the [Openwater Patent Pledge](Openwater%20Patent%20Pledge.pdf). Please review the pledge before using these patents in your work.

## ⚖️ Patent Pledge

The **Openwater Patent Pledge** grants anyone the right to use Openwater's patents for:

1. **Openwater Open Source Products** — Products based on designs released under Creative Commons Attribution-ShareAlike 4.0
2. **Openwater Derived Open Source Software** — Software based on code released under AGPL v3 or similar open-source licenses

### Key Terms

- ✅ Free to use for open-source medical device development
- ✅ Covers all current and future Openwater patents
- ✅ Legally binding and enforceable
- ⚠️ Subject to **Defensive Termination** if you sue Openwater for patent infringement

> **Full legal terms**: See [Openwater Patent Pledge.pdf](Openwater%20Patent%20Pledge.pdf)
